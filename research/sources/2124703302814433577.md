### Dench on how to turn Reddit into pipeline

**Go where buyers already describe their problem**
- People post on Reddit about problems they need solved, in their own words.
- Dench (YC S24) treats catching that intent as one of its highest-value plays.
- Pipeline gets built from those posts while the team sleeps.

**Treat speed as the whole game**
- A lead who posts on Reddit has a short shelf life.
- The best time to reply is minutes after someone posts, not hours.
- So the agents needed a reliable way to pull fresh posts on a schedule.

**Fix access before anything else**
- Dench's agents run in sandboxes, and Reddit blocks sandbox IP addresses.
- Without dependable web access, the agents could not reliably fetch new posts.
- Leads slipped past their window before anyone on the team could reply.

**Let the agent do the integration**
- Kumar sent his Dench CRM the Context.dev docs link and an API key.
- Then he asked it to find new Reddit posts every hour, as soon as they appear.
- That was the whole integration. The agent wired up the rest itself.

> "I just sent my Dench CRM the docs link and Context.dev API key and that was it." (Kumar Abhirup, Dench)

**Pull fresh posts every hour**
- Context.dev fetches new Reddit posts on a schedule without getting blocked.
- The agents see new buying intent as soon as it appears.
- Hourly pulls keep the team inside the window where a lead is still worth a reply.

**Surface only the hottest leads**
- Dench's agents monitor Reddit for buying intent and pass the hottest leads to the team.
- The team replies while the thread is still fresh, instead of finding it hours later.

**Pick infrastructure that agents can set up alone**
- A docs link and an API key were enough for Dench's own agent to finish the setup.
- No manual plumbing was needed between the CRM and the web.
- Kumar found Context.dev through YC Bookface and a tweet, then got on a call with Yahia.

**Turn the play into a product**
- Next, Dench plans to ship this RevOps setup out of the box.
- Every Dench customer who wants to run the same Reddit play will get it built in.

**What happened**
- $3M+ in pipeline opened from Reddit leads.
- All of it from conversations Dench would have missed before.
- Setup was one docs link and one API key, handed to its own agent.
- New Reddit posts are checked every hour, without being blocked.
