Title: "how i design landing pages and dashboards that actually stand out". Read 2026-11-24.

lessons.sh is Leo's free weekly letter. We cite it and link to it; the issue itself isn't copied here, so readers get the full piece by subscribing.

Points the course cites, paraphrased:

- Coding agents return the average template. Pick the audience, style, palette and fonts before any code, and keep them in the prompt. Examples: lessons.sh (warm white, lowercase type, black ink) and gradients.sh (a live GPU gradient on a dark canvas).
- Sketch five structurally different hero layouts side by side (Leo uses paper.design), then combine their best parts before building.
- Build the core 70 to 80%, then add one signature touch that fits the product. Examples: gradients.sh, dithercn.dev, email-sdk.dev and aisandboxbench.com.
- On landing pages, use one hero animation and short hover states, and no slow headline fade-ins. The issue's dashboard advice is product UI, so the course doesn't use it.
